# 🚀 AI Landing Page

A modern, fast, and fully responsive Landing Page built with **React 19**, **Tailwind CSS v4**, and **Vite**. The platform showcases AI agent environments, core benefits, interactive contact features, and sleek UI animations designed for optimal user experience across all devices.

🌐 **Live Demo:** [ai-land-page.netlify.app](https://ai-land-page.netlify.app/)

---

## ✨ Features

* **🌐 Navbar:** Sticky header with seamless smooth scrolling and a dedicated modern theme toggle.
* **🎯 Hero Section:** High-impact value proposition with interactive call-to-action buttons.
* **🤖 AI Types Section:** Detailed breakdown of various AI environments and architectures.
* **🚀 AI Benefits Section:** Grid overview highlighting key advantages and capabilities.
* **📩 Contact Section:** Interactive contact form for direct inquiries.
* **📝 Footer:** Clean layout with quick navigation links and dynamic current year.
* **📱 Fully Responsive:** Carefully styled for Mobile, Tablet, and Desktop screens.

---

## 🛠️ Tech Stack

* **Framework:** [React 19](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Hosting:** Netlify
